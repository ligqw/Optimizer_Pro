**ZeroBloat** — высокопроизводительный набор инструментов, написанный с нуля на **нативном C++ (Win32 API + Edge WebView2)**. В отличие от «оптимизаторов», которые сами являются тяжёлым софтом на Electron или .NET, ZeroBloat не требует громоздких сред выполнения, занимает всего несколько мегабайт ОЗУ, запускается мгновенно и работает напрямую с API Windows для максимальной эффективности.

> [!TIP]
> **Новое в [v13.0.0](https://github.com/ligqw/ZeroBloat/releases/tag/v13.0.0):** усиленная песочница WebView2 со строгой CSP, автоматический `audit.log`, отчёты о сбоях (minidump), фоновый ICMP-пинг и мониторинг здоровья и температуры дисков по S.M.A.R.T.

## Возможности

### 🧠 Умная оптимизация и диагностика
* **Smart PC Analyzer:** сканирует систему и формирует список безопасных, обратимых оптимизаций с оценкой экономии места на диске и уровнем риска.
* **Быстрый сканер диска по MFT:** молниеносный анализатор диска с интерактивной **Treemap**-визуализацией, которая показывает, какие файлы и папки занимают больше всего места.
* **Панель безопасности:** мгновенная проверка состояния Защитника Windows, брандмауэра, UAC и Центра обновления Windows.
* **Железо и здоровье дисков:** телеметрия в реальном времени для CPU, GPU (NVIDIA/AMD/Intel), VRAM, скорости сети, фонового ICMP-пинга и износа/температуры накопителей по S.M.A.R.T.

### 🚀 Игровой режим и производительность
* **Автоопределение игр и бустер:** автоматически определяет полноэкранные игры, повышает их приоритет и приостанавливает фоновые службы телеметрии и индексации (`SysMain`, `WSearch`, `DiagTrack`).
* **Игровые пресеты в один клик:** мгновенное переключение между профилями электропитания и реестра **Competitive FPS**, **Balanced** и **Quality**.
* **Твики реестра для низкой задержки:** оптимизация `Win32PrioritySeparation`, отключение Network Throttling, отключение алгоритма Нейгла для снижения пинга, отключение полноэкранных оптимизаций (FSO).
* **Скрытый разгон GPU:** тихо запускает MSI Afterburner в фоне и применяет сохранённый профиль, не засоряя рабочий стол.
* **LZX-сжатие игр:** прозрачно сжимает папки с играми штатным `compact.exe`, экономя гигабайты на SSD без ущерба для времени загрузки.

### 🧹 Глубокая очистка и управление памятью
* **Очистка кэшей уровня ISLC:** удаляет Temp, Prefetch, кэши браузеров и лаунчеров, остатки Windows Update и Delivery Optimization, шейдерные кэши DirectX/NVIDIA и миниатюры.
* **Очистка ОЗУ уровня Mem Reduct:** сбрасывает Standby-список, очищает список изменённых страниц и подрезает Working Set процессов; агрессивность настраивается (уровни 1–5), есть автозапуск по простою и по порогу.

### 🛠️ Системные инструменты и управление приложениями
* **Массовое удаление программ и Winget-менеджер:** пакетное тихое удаление программ (MSI, Inno Setup, NSIS) и обновление всего установленного ПО в один клик через официальные репозитории Microsoft Winget.
* **Менеджеры автозагрузки и служб:** полный контроль над автозапуском в реестре (`HKCU` / `HKLM`) и службами Windows (`Auto`, `Manual`, `Disabled`).
* **Контекстное меню Windows 11 и Shell Extensions:** переключение между классическим меню Win10 и новым меню Win11, отключение тормозящих сторонних расширений оболочки.
* **Безопасный редактор hosts:** встроенный редактор с автоматическими резервными копиями `.bak` и проверкой целостности после записи.
* **Файловые утилиты:** быстрый поиск дубликатов (по размеру и хешу заголовка), поиск больших файлов и надёжный **3-проходный шредер файлов**.

### 🎨 Современный интерфейс и оверлей в играх
* **13 динамических и статических тем:** фирменный матовый стеклянный интерфейс **Liquid Glass**, минималистичные пресеты (*Black, White, Midnight*) и плавные анимированные темы (*Void, Ocean, Neon, Forest, Crimson* и др.).
* **Настраиваемый оверлей в играх:** показывает важные для FPS метрики (CPU, GPU, VRAM, RAM, температуры, пинг) поверх полноэкранных игр; настраиваются позиция X/Y, прозрачность и тёмная/светлая тема.
* **Двуязычный интерфейс:** плавное переключение между **английским** и **русским**.

## Безопасность и защита

ZeroBloat разработан со строгими защитными механизмами, чтобы не навредить системе:
* **Защита от BSOD при работе с файлом подкачки:** перед изменением настроек подкачки (`DisablePagingExecutive`) проверяется объём физической памяти. Операция блокируется, если в системе **меньше 32 ГБ ОЗУ**.
* **Защита несистемных дисков:** критичные твики ОС (Lite Debloat, службы, реестр) автоматически скрываются, если в настройках выбран не системный диск.
* **Изолированная песочница WebView2:** интерфейс работает с локального виртуального хоста со строгой Content-Security-Policy (CSP), внешняя навигация заблокирована, на IPC-сообщения действуют жёсткие лимиты.
* **Автоматические бэкапы и журнал аудита:** перед изменением реестра или файла `hosts` создаются `.reg`- и `.bak`-точки восстановления с отметкой времени, а все критичные действия записываются в `audit.log`.
* **Неблокирующая асинхронная архитектура:** вся тяжёлая работа с диском, WMI и сетью выполняется в изолированных фоновых потоках с защитой по таймауту, поэтому интерфейс никогда не зависает.

## Установка и использование

1. Скачайте последнюю версию `ZeroBloat.exe` на странице [**Releases**](https://github.com/ligqw/ZeroBloat/releases).
2. Нажмите правой кнопкой мыши и выберите **Запуск от имени администратора** *(нужно для доступа к службам, реестру и WMI)*.
3. *(Необязательно)* Если на компьютере нет **Microsoft Edge WebView2 Runtime**, ZeroBloat проверит подпись Microsoft (Authenticode) и предложит тихую установку в один клик.

> [!NOTE]
> Исполняемый файл не подписан платным EV-сертификатом, поэтому при первом запуске Windows SmartScreen может показать предупреждение. Нажмите **Подробнее** → **Выполнить в любом случае**.

## Горячие клавиши и CLI

### Глобальные горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| `Ctrl` + `Alt` + `O` | Показать/скрыть диагностический оверлей в играх |
| `Ctrl` + `Alt` + `M` | Мгновенная очистка ОЗУ (Standby и Working Set) |
| `Ctrl` + `Alt` + `C` | Быстрая очистка Temp и сброс кэша DNS |

### Командная строка (CLI)
```bat
ZeroBloat.exe [параметры]
```

| Аргумент | Описание |
| :--- | :--- |
| `--portable` | Хранить настройки, бэкапы, логи и кэш WebView2 рядом с `ZeroBloat.exe` (удобно для флешки). |
| `--silent` | Запуск сразу свёрнутым в системный трей. |
| `--no-admin` | Запуск без прав администратора (часть функций будет недоступна). |
| `--help` | Показать список доступных параметров командной строки. |

## Сборка из исходников

### Требования
* **Visual Studio 2022** (с рабочей нагрузкой *Разработка классических приложений на C++*) или MSVC Build Tools
* **Windows SDK** (`10.0.22621.0` или новее)
* **WebView2 SDK** (`Microsoft.Web.WebView2` через NuGet)
* Компилятор с поддержкой **C++20** (MSVC `cl.exe`)

### Шаги сборки
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ligqw/ZeroBloat.git
   cd ZeroBloat
   ```
2. Установите WebView2 SDK через NuGet (`Microsoft.Web.WebView2`).
3. Откройте **x64 Native Tools Command Prompt for VS 2022** и скомпилируйте `ZeroBloat.cpp` с помощью MSVC. Используйте ту же команду и библиотеки, что в [`.github/workflows/build.yml`](.github/workflows/build.yml), и обязательно укажите флаги `/std:c++20` и `/utf-8` (`/utf-8` нужен, чтобы русские строки интерфейса не превращались в кракозябры).
4. Либо сделайте форк репозитория и запустите workflow **GitHub Actions**: он соберёт `ZeroBloat.exe` на `windows-latest` и опубликует его как артефакт сборки.

> [!NOTE]
> Нужные библиотеки Windows и `WebView2LoaderStatic.lib` подключаются через `#pragma comment` в исходнике, поэтому дополнительной ручной линковки не требуется — достаточно указать пути к WebView2 SDK.
